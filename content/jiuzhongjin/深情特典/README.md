# 《九重燼》深情特典（Romance IF / Specialverse）說明

本目錄收錄六大女主角各自專屬的純愛感情線擴展篇章。

---

## 1. Canon 定位：Romance IF / Specialverse

- **定位**：本系列篇章屬於 **Romance IF / Specialverse**（專屬感情平行世界線）。
- **互斥性**：六篇特典各自代表蕭承淵與該位女主角走到終局的專屬深情篇章，**彼此互斥**，不與其它五位女主的特典同時成立。
- **與小說正史之關係**：不覆蓋亦不更改《九重燼》小說正傳 48 章（Novel Canon）之唯一正史結局。
- **世界觀要求**：各篇依然嚴格遵循 `docs/DASHENG_SHARED_WORLD_BIBLE.md` 架空世界規範，不得出現地球真實歷史專名、地名、朝代典籍或特產。

---

## 2. 篇章目錄

1. **柳如煙篇**：[〈煙川照雪〉](./深情特典_柳如煙篇_煙川照雪.md) —— 江南煙川孤舟，梅香雪霽，筆硯相伴的靈魂知己。
2. **顧清漪篇**：[〈解甲共老〉](./深情特典_顧清漪篇_解甲共老.md) —— 朔雪長關，長纓卸甲，並轡馳騁於塞北天地的生死戰友。
3. **沈夢蝶篇**：[〈燈下照影〉](./深情特典_沈夢蝶篇_燈下照影.md) —— 聽雨殘照，洗淨脂粉，終得一片澄湖月色的雙棲白蝶。
4. **卓雲翎篇**：[〈同袍〉](./深情特典_卓雲翎篇_同袍.md) —— 寒鐵重甲，烽火並肩，誓與君同袍共死的宿命將星。
5. **阿依娜篇**：[〈赤漠星歌〉](./深情特典_阿依娜篇_赤漠星歌.md) —— 大漠篝火，赤月金鈴，橫跨萬里絲路的盟好與熾熱。
6. **白蘅篇**：[〈人間煙火〉](./深情特典_白蘅篇_人間煙火.md) —— 臨川藥廬，苦甘草木，守護天下蒼生與平凡炊煙的溫厚相守。
