# 《九重燼》番外分類說明

本目錄目前收錄的九篇番外，均以互動小說遊戲版 EXTRA_STORIES / Ink 番外為基礎改寫成 prose 版本。

因此本目錄預設分類為：

> **Gameverse prose adaptations / 互動小說 Game Canon 番外小說化**

它們不是 48 章小說正傳 `NOVEL_CANON.md` 的直接延伸。

---

## Canon 依據

本目錄內容優先遵守：

1. `docs/GAME_CANON.md`
2. `docs/DASHENG_SHARED_WORLD_BIBLE.md`
3. 對應的 `docs/EXTRA_STORIES/EXTRA_*.md`
4. 對應的 `src/narrative/chapters/extra_*.ink`

不應使用 `NOVEL_CANON.md` 強制覆蓋遊戲專屬劇情。

---

## 因此可以保留的 Game Canon 設定

例如：

- 念煙在遊戲主線第八章為四歲八個月
- 原主／柳如煙的遊戲版舊情與身世線
- 帝王手札、輪迴或靈魂異常相關設定
- 端王蕭承昱與遊戲派系設定
- 依不同 Ending 延伸出的角色狀態
- 遊戲路線中的角色死亡／存活差異

上述內容與 48 章小說正史不同，不視為 bug。

---

## 仍應共用的世界層

雖然劇情採 Game Canon，長期仍建議玩家／讀者可見文字逐步遵守 Shared World：

- 北朔（legacy 北朔）
- 玄沙關（legacy 玄沙關）
- 焉岐國（legacy 焉岐）
- 烏烈汗國（legacy 烏烈）
- 昭京、九闕宮城等

internal ID、Ink flag、asset id 可保留 legacy 名稱。

## 未來小說正史番外

如果未來要寫接續小說第 48 章〈煙雨故人〉的正式小說番外，請不要放在本目錄混用。

建議新增：

`novel/小說正史番外/`

該目錄內容改以：

1. `NOVEL_CANON.md`
2. `DASHENG_SHARED_WORLD_BIBLE.md`

為最高依據。

---

## 標示建議

每篇 Gameverse prose adaptation 若未來公開發布，可在文首加入：

> 本篇為《九重燼》互動小說世界線番外小說化，屬 Game Canon；與小說正傳 48 章為平行世界線。

避免讀者誤以為念煙年齡、角色關係或 Ending 狀態是小說正史設定。
