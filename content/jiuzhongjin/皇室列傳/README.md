# 《九重燼》皇室列傳・Novelverse Royal Chronicles

本目錄收錄《九重燼》小說宇宙之**皇室列傳（Novelverse Royal Chronicles）**，記錄大晟皇朝父子兄弟八位核心皇室人物之生平宿命、心術博弈與奪嫡內幕。

---

## 1. Canon 定位與規範

- **所屬層級**：Novelverse Royal Chronicles（小說宇宙正統皇室紀傳）。
- **世界線基準**：與小說正傳四十八章（`novel/卷一_藏鋒`、`novel/卷二_入局`、`novel/卷三_九重`）及《人物志》同屬同一 Novel Canon 世界線，完全遵循：
  - [NOVEL_CANON.md](../../docs/NOVEL_CANON.md)
  - [NOVEL_CHARACTER_STATUS_MATRIX.md](../../docs/NOVEL_CHARACTER_STATUS_MATRIX.md)
  - [DASHENG_SHARED_WORLD_BIBLE.md](../../docs/DASHENG_SHARED_WORLD_BIBLE.md)
- **重大歷史收束原則**：
  - **年號紀年**：嚴格使用「景和」年號（老皇帝為前景和＝蕭景衡；九殿下登基為後景和＝蕭承淵，景和元年至七年）。小說舊稿年號「建平」已全面退役廢止。
  - **靖王命運**：四皇子靖王蕭承烈於宮變之夜（朔門之變）看破外戚偽令，在朔門單騎叩關、投戈止戈，交出中央禁軍與虎符兵權；新朝免死除權，保留王爵受節制，永鎮塞北，**絕非自刎戰死，亦不得追封為「忠武烈王」**。
  - **端王命運**：大皇子端王蕭承昱監國失敗，宮變後降封順王，幽居別宮歸田。
  - **禁軍番號**：九殿下直屬精銳禁軍統一名為**玄策軍**（嚴禁混用「神策軍」）。
  - **宮殿地名**：大晟正殿統一名為**承天殿**（嚴禁混用「太和殿」）；皇城北門統一名為**朔門**（嚴禁混用「玄武門」）。
