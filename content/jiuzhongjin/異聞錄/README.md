# 《九重燼》異聞錄・Gameverse IF

本目錄收錄《九重燼》之**異聞錄（Gameverse IF）**。本系列取材自互動遊戲 Demo 與正式版中的各項多重分歧結局（Gameverse Endings），以長篇小說體裁展開各條截然不同的世界線可能。

---

## 1. Canon 定位與規範

- **所屬層級**：Gameverse IF / Gameverse Extra（遊戲分歧結局衍生世界線）。
- **世界線屬性**：
  - **非小說正史**：本系列內容屬於「平行可能（IF 線）」，**不代表**小說正傳 48 章（`novel/卷一_藏鋒`、`novel/卷二_入局`、`novel/卷三_九重`）之唯一正史走向。
  - **遊戲衍生**：每卷均嚴格對應遊戲結局系統（見 [ENDING_CONDITIONS.md](../../docs/ENDING_CONDITIONS.md)）之特定 Ending ID。
- **世界觀詞彙**：雖然情節為 IF 分歧，但基礎世界觀仍遵循 [DASHENG_SHARED_WORLD_BIBLE.md](../../docs/DASHENG_SHARED_WORLD_BIBLE.md)（如正殿為承天殿、北門為朔門、精銳軍為玄策軍等）。
