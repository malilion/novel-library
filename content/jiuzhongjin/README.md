## 總序・九重宮闕的風煙與人性

《九重燼》是一部以架空王朝「大晟」為背景的嚴肅古風歷史政治群像長篇小說。故事發端於現代歷史學者靈魂穿越至大晟最卑微多疑的第九皇子蕭承淵之身，自承華殿的一灘血泊與半枚鳳尾白玉起筆，層層剝繭，直指三百年皇統背後深不見底的皇權猜忌、世家吸血、邊陲烽火與后宮冤案。

全書嚴格遵循「拒絕降智臉譜化、拒絕現代快餐網梗、恪守傳統古風文學厚重質感」的原則，將每一位登場者——無論是帝王、皇子、名將、名士、女官、番邦王女，乃至市井藥童與邊關無名小卒，皆作為具有獨立命運尊嚴的「人」來書寫。

本目錄為全書正式典藏總導讀，統攝全書**六大模組、共八十二卷篇章（逾七十八萬字）**，為讀者與編纂者提供最清晰的閱讀與檢索指引。

## 皇室列傳（全八卷・天潢貴冑宿命群像）

> 深度聚焦大晟至高權力頂點上的父子與兄弟。老龍暮年猜忌、長兄如父的重擔、鐵血名將的孤勇、清流雅士的妥協、商海博弈的暗潮、道家辟穀的防線、風月紈絝的佯狂、懵懂少年的赤誠——每一卷皆為一曲在皇權血腥碾壓下的人性悲歌。

- [皇室列傳・帝王卷：老龍心術](./皇室列傳/皇室列傳_帝王卷_老龍心術.md)  
  *主角：先帝・蕭景衡*  
  **至高皇權與暮年猜忌**。「朕富有四海，卻無一人可信。」夜半巡視太廟、面對廢太子二皇子靈位的隱秘自白、對淑妃之死的二十年冷酷心結，以及對九子奪嫡的縱容與推手——這是一頭坐在龍椅上親手磨鈍所有爪牙的老龍悲劇。
- [皇室列傳・長兄卷：端王承昱](./皇室列傳/皇室列傳_長兄卷_端王承昱.md)  
  *主角：皇長子・端王蕭承昱*  
  **長兄如父與宗法枷鎖**。身為無嫡長子，背負三十年的「長子當國」重擔與宗室期許。朝堂上為百官求情、私下裡替幼弟們遮風擋雨；當奪嫡的血腥將兄弟推向兩極，他在護全宗族與帝王猜忌間的最後抉擇。
- [皇室列傳・將星卷：靖王承烈](./皇室列傳/皇室列傳_將星卷_靖王承烈.md)  
  *主角：皇四子・靖王蕭承烈*

- [皇室列傳・清流卷：寧王承翊](./皇室列傳/皇室列傳_清流卷_寧王承翊.md)  
  *主角：皇三子・寧王蕭承翊*  
  **名士風骨與君子困局**。天下清流領袖、文人墨客的精神領袖。在父皇的權謀試探與士林道統的重壓下，他試圖用儒家王道調和血腥政治，卻在面對柳家獲罪、朋黨黨錮時經歷了最深沉的信仰崩塌與重塑。
- [皇室列傳・市舶卷：安王承祁](./皇室列傳/皇室列傳_市舶卷_安王承祁.md)  
  *主角：皇五子・安王蕭承祁*  
  **金山銀海與布衣算盤**。掌管大晟市舶司與天下鹽鐵茶馬。世人笑他是滿身銅臭的商賈王爺，不知他以無窮金帛在暗中撬動各省糧道與邊防軍費。他的每一筆帳，皆是買下一條命的代價。
